# RFC Process

Owner: Engineering (current owner: @jebre)
Last reviewed: 2026-02-10
Status: Active
Scope: Proposing and reviewing larger implementation changes.

## When To Write an RFC

- Change touches multiple backend apps or frontend features.
- Change introduces migration/infra risk.
- Change modifies user workflows significantly.

## Workflow

1. Create RFC from template: `/Users/jebre/Desktop/hms/docs/templates/rfc-template.md`.
2. Share for async review and collect feedback.
3. Resolve open questions and document final decision.
4. Convert final decision to ADR when architecture is affected.
