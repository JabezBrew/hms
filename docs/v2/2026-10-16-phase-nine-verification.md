# Clinical note evidence and scoped nursing decisions

Status: frozen local acceptance and independent reviews passed.
Browser and staging checks remain pending previously
requested approvals. Full Python parity is not claimed.

Clinical notes now use strict UUID commands, immutable versions, pinned template
revisions, author/explicit-admin amendment authority, reasoned CAS amendments,
lean history and protected exact-version reads. Templates have bounded server
catalog queries, owned versioned changes and immutable original receipts.
Historical unknown authors and malformed template bodies are preserved rather
than assigned invented provenance. Old unsafe writers are explicitly retired.
Destructive demo reseeding refuses to delete retained clinical evidence.

Chronicle provides the corresponding note detail, history, amendment and creation
workspaces. The template catalog uses real server paging and active/inactive
management. Lost responses can retry only the same reviewed UUID/body. Copied
text, queries and callbacks are fenced on scope changes; closed dialogs retain
only the appropriate controller state. Draft controls describe local unsaved
work honestly. No signing or mandatory administrator publication is invented.

Nursing tasks, observations, alerts and vitals enforce live clinical visibility,
current feature entitlement, actor/session/deadline and actual ward authority
after database waits. Filters precede pagination. Terminal task decisions retain
the first actor/time, reject opposite decisions and preserve legacy unknown
provenance. Vital/task creates compare any explicit patient intent with the
actual admission; empty observations and ignored terminal bodies are rejected.

The UI uses complete bounded windows, selected-admission vital entry, confirmed
write receipts, explicit uncertainty and reachable task pagination. Rust decisions
do not optimistically report completion. Scope changes suppress old callbacks
and remove copied clinical data.
